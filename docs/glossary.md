# Glossary

Shared vocabulary for the personal expenses app. Use these terms consistently in intents, specs, and code.

| Term | Arabic | Meaning |
|---|---|---|
| User | المستخدم | A person who logs in (via Breeze) and records their own expenses. |
| Category | التصنيف | A label used to group expenses (e.g. Food, Transport). Has a name. |
| Expense | المصروف | A single spending record: amount, description, date, and category. |
| Amount | المبلغ | How much money was spent in one expense. |
| Monthly summary | الملخص الشهري | A page showing the total for a month and the total per category. |
| Filter | الفلترة | Narrowing the expense list by month and/or category. |
